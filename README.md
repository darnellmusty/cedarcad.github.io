# CedarCAD Alpha 0.1

An early browser-based segmented turning design prototype for volunteer usability testing.

Open the [tester's guide](./tester-guide.html) for testing instructions and limitations.

> **Alpha warning:** Cutting and feature ring construction instructions are experimental and not shop-validated. Independently verify dimensions, tool setups, and safety before cutting wood.

To publish using GitHub Pages, select **Settings → Pages → Deploy from a branch**, branch **main**, folder **/(root)**, and save.

Because this repository belongs to `darnellmusty` rather than being named `darnellmusty.github.io`, the likely project-site address is `https://darnellmusty.github.io/cedarcad.github.io/` after Pages is activated.
